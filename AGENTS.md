# sv3.network

sv3.network is the Web3-native version of SignVault.io - turning documents into on-chain Real-World Assets (RWAs) with verifiable e-signatures, organizations, and compliance workflows on any EVM chain.

Package manager: pnpm.

## Commands

- dev: `pnpm dev`
- build: `pnpm build`
- test: `pnpm test`

## Layout

- `docs/`
- `packages/`

## Rules

- Run `pnpm test` before you say a change is done.
- Never commit secrets or `.env` files.
