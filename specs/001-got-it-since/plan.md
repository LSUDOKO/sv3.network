## Summary
Create a web3-native version of SignVault (sv3.network) that transforms traditional document management into a blockchain-based system. The approach includes wallet authentication, smart contracts for organizations and documents, IPFS storage, and on-chain digital signatures, all within a 24-hour hackathon timeframe.

## Technical Context
**Language/Version**: Solidity, TypeScript/JavaScript (React 19, Next.js 15)
**Primary Dependencies**: Hardhat/Foundry, wagmi/viem, ethers.js, IPFS, WalletConnect, RainbowKit
**Storage**: PostgreSQL (existing), IPFS for documents, Blockchain for metadata/signatures
**Testing**: Hardhat testing framework, React testing library, integration tests
**Target Platform**: Web application, Multiple EVM chains (Base, Sepolia, Avalanche Fuji)
**Project Type**: web - frontend + blockchain backend
**Performance Goals**: <5 second document upload, <2 second signature verification, 100% wallet connection success
**Constraints**: 24-hour hackathon timeframe, MUST complete core functionality
**Scale/Scope**: Hackathon MVP, Single organization, Multiple documents per organization, Multiple signatures per document
